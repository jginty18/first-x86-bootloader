# first-x86-bootloader
<b>What it does:</b> A 512-byte boot sector that displays a message using BIOS video services.

<b>Tools:</b> NASM, Bochs 3.1, and Windows.

<b>Build command:</b> nasm -f bin boot.asm -o boot.com

<b>What I learned:</b> Compiling assembly, configuring a simulated floppy drive, and troubleshooting boot errors.

<b>Credit:</b> www.joe-bergeron.com/posts/Writing%20a%20Tiny%20x86%20Bootloader/
