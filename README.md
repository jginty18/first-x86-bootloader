# first-x86-bootloader
What it does: A 512-byte boot sector that displays a message using BIOS video services.
Tools: NASM, Bochs 3.1, and Windows.
Build command: nasm -f bin boot.asm -o boot.com
What I learned: Compiling assembly, configuring a simulated floppy drive, and troubleshooting boot errors.
